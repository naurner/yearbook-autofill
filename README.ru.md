# Автозаполнение выпускных альбомов (Photoshop)

## Что нужно
- Photoshop 2026, Python 3 с пакетами `openpyxl pillow fonttools`
  (`python -m pip install openpyxl pillow fonttools`).
- Установленные шрифты шаблона (папки `fonts`/`font` рядом с шаблоном).

## Как заполнить альбом
1. Скопируйте `templates/<Шаблон>.xlsx` (например `templates/Flight.xlsx`) и заполните:
   - лист «Поля» — класс, год, школа, учителя, цитаты; пустая ячейка = как в шаблоне;
   - листы «Стр …» — строка = ячейка на странице (номера — на картинках в `templates/<Шаблон>_схема`),
     в «Фото (файл)» — имя файла из папки с фото.
2. Проверьте без запуска Photoshop:
   `python fill_album.py --template Flight --excel 11A.xlsx --photos D:\фото\11A --out D:\альбомы\11A --check`
3. Запустите то же без `--check`. Закройте в Photoshop исходные PSD шаблона.
   На каждую страницу появятся `<стр>.psd` (со слоями), `<стр>.jpg` и `<стр>.pdf`.
   Только часть страниц: `--pages cover,01`.

## Как это устроено
- Фото вписывается в рамку с заполнением и обрезкой (по горизонтали — центр, по вертикали — ближе к верху)
  и ставится обтравочной маской на слой-рамку: форма и эффекты рамки сохраняются.
  Скрытый в шаблоне слот фото при заполнении включается.
- Текст заменяется в том же слое: шрифт, цвет, поворот сохраняются; если в строке несколько стилей,
  i-е слово получает стиль i-го слова образца. Если текст длиннее места — он уменьшается
  (не меньше 60 %), это видно в отчёте.
- Исходные PSD не изменяются никогда.
- Если изменили PSD-шаблон (двигали/добавляли слои) — пересоберите манифест:
  `python build_manifests.py --templates <Шаблон>`.
- Тестовые данные для проверки: `python make_demo_data.py --template Flight` → `demo/Flight/`.
- Тесты: `python -m pytest`.

# Виньетки: отдельный PDF на каждого ученика

Результат: `<папка вывода>/<Класс>/<Фамилия Имя>.pdf` — личная обложка (фото и имя ученика)
+ страницы альбома (сетка класса, учителя, цитаты, страницы с групповыми фото, выбранными учеником).

## Как собрать класс
1. Пустая таблица для шаблона: `python vignette.py table --template Flight --out 11А.xlsx`
2. Заполните:
   - «Класс» — название класса (имя папки), год, класс, школа, учителя, общие фото класса
     (например фото классного руководителя). Пустая ячейка = как в шаблоне. Год пишется один раз
     (2025) — на страницах он сам разойдётся как «2025», «20 / 25», «“25».
   - «Ученики» — строка на ученика: «Фамилия Имя», фото для обложки, фото для сетки, цитата,
     групповые фото через запятую, доп. страницы через запятую (номер или название из листа
     «Страницы»; пусто = все). Обязательные страницы входят всегда.
   - «Учителя» — фото и подпись («ФИО / предмет»).
   - «Общие фото» — групповые фото по умолчанию: ими добиваются места, если ученик выбрал меньше
     (если фото меньше, чем мест, они повторяются — будет предупреждение).
   Фото ищутся во всех подпапках папки класса, расширение можно не писать.
3. Проверка: `python vignette.py check --template Flight --excel 11А.xlsx --photos D:\фото\11А`
4. Превью с водяным знаком (без Photoshop, секунды):
   `python vignette.py preview --template Flight --excel 11А.xlsx --photos D:\фото\11А --out D:\вывод`
   → `D:\вывод\<Класс> (превью)\`.
5. Печать (Photoshop): `python vignette.py build ... --out D:\вывод` → `D:\вывод\<Класс>\`.
   Одинаковые страницы рендерятся один раз; повторный запуск досчитывает только новое
   (кэш в `<Класс>\_страницы`). Только некоторые ученики: `--only "Абишева Алия, Азимбеков Эльдар"`.
   PSD страниц: `--psd`.

## Как это устроено
- `configs/<шаблон>.json` — роли страниц (обложка / сетка / учителя / групповые фото), какие надписи
  объединены в одно поле, куда идут имя и фото ученика. После правки PSD-шаблона:
  `python build_manifests.py --templates <шаблон>`, при необходимости поправить конфиг,
  затем `python vignette.py compile --template <шаблон>`.
- `compiled/<шаблон>/` — разобранный для превью шаблон (картинки слоёв, маски, тексты, шрифты):
  его достаточно для превью на сервере без Photoshop.
- Демо-класс: `python make_demo_class.py --template Flight` → `demo_class/Flight/`.

# Telegram-бот: ученики сами собирают свои виньетки

Ученики по ссылке класса вводят фамилию и имя, выбирают доп. страницы (в пределах тарифа класса),
номера кадров для обложки и сетки (бот показывает кадр для подтверждения), цитату и номера групповых
фото. Когда заполнит весь класс, каждый получает PDF-превью с водяным знаком и кнопки
«Одобрить» / «Изменить». Студия видит сводку по классу и выгружает таблицу для печати.

## Запуск
1. В Telegram у @BotFather: `/newbot` → получите токен.
2. Узнайте свой Telegram id (например у @userinfobot).
3. Скопируйте `bot.env.example` в `bot.env` и впишите `BOT_TOKEN` и `ADMIN_IDS`.
4. Запустите `run_bot.bat` (или `python -m bot.main`). Пока окно открыто — бот работает.
   База, скачанные фото и превью — в `bot_data/` (или `DATA_DIR`).

## Студия (администратор)
- `/new` — новый класс: шаблон, название, число учеников, тариф (сколько доп. страниц), где фото
  (папка на компьютере с подпапками «портретки»/«общие» или ссылка с `{num}` вместо номера кадра),
  общие надписи (год, класс, школа…), общие фото класса, групповые фото по умолчанию.
  В конце — ссылка-приглашение для учеников.
- `/classes` — классы: сколько заполнили/одобрили, «Напомнить», «Превью сейчас», «Таблица xlsx»,
  «Собрать для печати» (если на этом компьютере есть Photoshop), «Закрыть класс».
- Таблица xlsx из бота — та же, что для `vignette.py build`: фото в ней указаны номерами кадров.

## Работа на сервере
Бот не требует Photoshop: превью делает `compiled/`. На VPS укажите фото ссылками с `{num}` —
бот скачает нужные кадры сам. Печать — на компьютере с Photoshop по таблице из бота.
